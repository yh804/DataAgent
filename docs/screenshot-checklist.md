# 截图清单

> 统一要求:窗口 **1440×900**,中文界面,使用 `demo_sales.csv`,新建会话;
> 截图前关闭终端、编辑器与任何包含密钥或绝对路径的窗口。
> 不允许出现:API Key、盘符开头的绝对路径、用户主目录路径、真实姓名、浏览器书签栏。

## 通用裁切规则

| 区域 | 处理 |
|---|---|
| 浏览器书签栏 / 地址栏下拉历史 | 裁掉,只保留地址中的 `127.0.0.1:8000` 或整个地址栏 |
| 终端窗口 / 日志 | 不出现在截图内 |
| 左栏「会话」「历史运行」中不适合讲解的历史项 | 可保留,但不要在讲解中点开 |
| 报告里的文件路径 | 只保留 `outputs/...` 相对路径,出现盘符路径时重新裁切 |
| 右侧滚动条、系统通知 | 裁掉 |

## 01-approval-card.png

用途:README「它能做什么」第一张图;证明「计划先给人看」。

必须出现:

- `demo_sales.csv` 文件名(输入框上方的附件 chip 与计划卡标题都要出现);
- 折叠卡标题行的「共 N 步」与首步摘要;
- 展开后的计划步骤列表(至少 3 步);
- 审批理由「首次分析该数据集」;
- 复选框「本会话信任该数据集,不再询问」;
- 「运行」「编辑」「取消」三个按钮。

拍摄步骤:新会话 → 点输入框左侧 📎 → 在菜单里选已有数据集 `demo_sales.csv`(不触发上传)
→ 输入「按月看订单金额趋势并画图」→ 弹出审批卡 → 点击标题展开 → 截图。

必须裁掉:输入框上方的历史消息(如有)、右栏未加载的空面板。

## 02-report.png

用途:README 第二张图;证明「结论 + 图表 + 可复现」。

必须出现:

- 右栏「报告」页签处于选中态;
- 「一句话结论」「关键发现」「建议」「局限与数据质量」「口径与数据版本」五节;
- 「口径与数据版本」中的指纹(文件名@sha256 前 12 位)、行数 `1200`、编码;
- 左栏或中栏能看到同一轮的节点 chip 已全部点亮。

拍摄步骤:完成 01 后点「运行」→ 等结果卡出现 → 右栏切到「报告」→ 滚到「口径与数据版本」→ 截图。
如需同时展示图表,可再补一张 `02b-charts.png`(非必需),但 README 只引用 02-report.png。

必须裁掉:报告末尾「附录:原始输出」中的大段 stdout(可滚动到该节上方)。

## 03-history.png

用途:README 第三张图;证明「可观测 + 可治理」。

必须出现:

- 左栏「历史运行」列表(至少 2 条 run,含时间与状态);
- 右栏「Trace」页签的节点耗时表;
- 左栏「会话」列表中的至少 1 个会话行,鼠标悬停时可见垃圾桶图标;
- 如有删除确认弹窗,只截弹窗本身,不截背后的其他会话标题。

拍摄步骤:完成第 3 步追问后 → 点「历史运行」第一条 → 右栏切到「Trace」→ 截图;
删除动作另拍 `03b-delete-confirm.png`(可选)。

必须裁掉:Trace 页中可能出现的绝对路径字段;只保留节点名与耗时。

## 发布前自检

1. 三张图都是 1440×900,中文界面,文件名与 README 引用一致;
2. 图中没有 Key、没有盘符绝对路径、没有用户主目录路径、没有真实姓名;
3. 图中数据均来自 `demo_sales.csv`,行数显示 1200;
4. 01 必须能看到审批理由,02 必须能看到数据指纹,03 必须能看到 Trace;
5. 截图压缩后体积可控(单张 < 500KB),放入 `docs/images/` 并确认 README 链接可点。
